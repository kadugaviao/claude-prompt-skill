**Tipo:** Escrita / comunicação · **Modo sugerido:** normal · **Raciocínio:** normal

```text
Objetivo: Escreva uma mensagem curta para o canal do time no Slack avisando que o deploy de sexta-feira (13/11/2026) foi adiado. Quem ler precisa saber na hora o que mudou e se tem que fazer alguma coisa, sem precisar perguntar no thread.

Contexto:
- Público: o time de desenvolvimento (devs, QA e talvez produto). Todos já sabiam do deploy de sexta.
- Nova data: [NOVA DATA ou "a definir"]
- Motivo: [MOTIVO EM 1 FRASE, ou "omitir"]
- O que muda para o time: [ex.: "o code freeze continua valendo" / "podem continuar mergeando na main" / "nada"]
- Responsável ou contato para dúvidas: [NOME ou @canal]

Tarefa:
1. Escreva a mensagem em português, com tom direto e cordial, do jeito que se fala entre colegas no Slack.
2. Comece pela notícia ("O deploy de sexta (13/11) foi adiado"), depois diga a nova data, o motivo e o que o time precisa fazer, nesta ordem. Quem lê só a primeira linha já precisa entender o principal.
3. Use a formatação do Slack (*negrito* com asterisco simples) só para a data nova. Use no máximo um emoji, e só se combinar com o tom.
4. Se algum campo entre colchetes estiver vazio, deixe o marcador [assim] no texto em vez de inventar informação. Uma data ou um motivo errado causa mais confusão do que um campo em branco.

Restrições:
- No máximo 5 linhas. Mensagem longa no Slack acaba não sendo lida.
- Não use @channel nem @here, a menos que o contexto peça. Esses comandos notificam todo mundo, e quem decide isso é o autor.
- Não envie nem publique a mensagem. Só entregue o texto, porque quem posta é o usuário.

Pronto quando:
- A primeira linha diz que o deploy de sexta foi adiado.
- A nova data (ou "a definir") e a ação esperada do time aparecem de forma explícita.
- Nenhuma informação foi inventada além do contexto acima.

Formato da resposta: a mensagem pronta dentro de um bloco de texto para copiar e colar. Depois, em uma linha, uma variação mais curta (1 a 2 linhas) para quem preferir algo mais enxuto.
```
