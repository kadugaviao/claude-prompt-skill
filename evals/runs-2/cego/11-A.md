Contexto:
- Maven com wrapper (`./mvnw`), Java 21, parent `spring-boot-starter-parent` 3.3.5 em `pom.xml`.
- Dependências: starter-web, starter-data-jpa, starter-security, postgresql (runtime), starter-test e também JUnit 4.13.2 + junit-vintage-engine.

Tarefa:
1. Levante o que muda do Boot 3.3 para o 4.x e afeta este projeto: Spring Framework 7, Spring Security 7, Hibernate 7 / JPA, Jackson 3, os starters que foram renomeados ou divididos em módulos, as propriedades que mudaram de nome ou foram removidas, e o suporte a JUnit 4/vintage. 6. Remova o `spring-boot-properties-migrator` no final.
7. Faça um commit por passo concluído (3.5, testes, 4.x), com mensagem descritiva.
