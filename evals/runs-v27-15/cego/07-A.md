**Tipo:** Pesquisar ou comparar · **Modo:** normal · **Esforço:** padrão

```text
Sugira um nome para o repositório deste projeto no GitHub e recomende uma licença.

## Contexto
O projeto é uma skill do Claude Code chamada `/prompt`. Ela transforma um pedido escrito às pressas em um prompt estruturado, seguindo as boas práticas da Anthropic. O repositório tem só Markdown: `README.md`, `prompt/SKILL.md` e `prompt/tipos.md`. Ainda não há arquivo de licença nem remote configurado. Hoje a pasta local se chama `skillproj`. A instalação é `cp -r prompt ~/.claude/skills/`.

## Insumos
Arquivos a ler: `README.md`, `prompt/SKILL.md`.

## Tarefa e escopo
1. Nome: proponha de 3 a 5 nomes e avalie cada um por estes critérios: deixa claro o que a skill faz, é curto e fácil de digitar em `git clone`, não confunde com produtos ou marcas da Anthropic e não colide com repositórios conhecidos no GitHub (pesquise para conferir). Escolha um.
2. Licença: compare MIT, Apache-2.0 e CC-BY-4.0 (e outras, se fizerem sentido) para um repositório de prompts e instruções em Markdown que outras pessoas vão copiar e adaptar. Considere a facilidade de reuso, a exigência de atribuição, a proteção de patente e se a licença foi feita para código ou para texto. Escolha uma.
Fora do escopo: criar o repositório, renomear a pasta ou adicionar o arquivo `LICENSE`, porque a tarefa é só de recomendação.

## Restrições
- Não altere arquivos nem rode comandos git que mudem o estado, porque a tarefa é só de leitura e pesquisa.
- Separe o que é fato (texto da licença, resultado da busca) do que é opinião sobre o nome.
- Use fontes primárias para as licenças (choosealicense.com, opensource.org, creativecommons.org), com a data de acesso.

## Autonomia
Suposições: confirme: o repositório será público e a ideia é deixar qualquer pessoa usar e modificar livremente. Confirme: o nome pode ser em inglês, para alcançar mais gente no GitHub, mesmo com o conteúdo em português. Diga se alguma delas estiver errada.

## Formato da resposta
1. Resposta direta em 1–2 frases: o nome escolhido e a licença escolhida.
2. Tabela dos nomes: nome | clareza | tamanho | colisão encontrada.
3. Tabela das licenças: licença | reuso | atribuição | patente | adequada a texto/código.
4. Recomendação com confiança (alta, média ou baixa) e o porquê, para o nome e para a licença.
5. Fontes: link e data.
```
