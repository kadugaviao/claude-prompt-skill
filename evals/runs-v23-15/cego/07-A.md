## Resposta final

**Tipo:** Pesquisar ou comparar · **Modo:** normal · **Esforço:** padrão

```text
Sugira um nome para o repositório deste projeto no GitHub e recomende uma licença. Eu vou usar a resposta para criar o repositório público e o arquivo LICENSE.

## Contexto
- O projeto é uma skill do Claude Code chamada `/prompt`. Ela transforma um pedido informal em um prompt estruturado, seguindo as boas práticas da Anthropic.
- O conteúdo é só Markdown: `README.md`, `prompt/SKILL.md` e `prompt/tipos.md`. Não há código executável nem dependências.
- O repositório git é local, sem remote configurado e sem arquivo LICENSE. A documentação está em português.
- A instalação é `cp -r prompt ~/.claude/skills/`, então a pasta `prompt/` é o que o usuário final copia.

## Insumos
Arquivos a ler: `README.md`, `prompt/SKILL.md`, `prompt/tipos.md`.

## Tarefa e escopo
1. Proponha de 3 a 5 nomes de repositório. Avalie cada um por: clareza sobre o que o projeto faz, tamanho, facilidade de busca e conflito com repositórios já existentes no GitHub. Para checar conflitos, use `gh search repos <nome>` ou uma busca web e informe quantos resultados encontrou.
2. Compare de 3 a 4 licenças adequadas a um projeto feito só de texto e prompts, por exemplo MIT, Apache-2.0 e CC BY 4.0. Os critérios são: permite reuso e modificação, exige atribuição, serve para texto ou para código, e é reconhecida pelo GitHub (detecção automática).
3. Escolha um nome e uma licença e justifique.
Fora do escopo: criar o repositório, o LICENSE ou editar arquivos, porque a tarefa é só de recomendação.

## Restrições
- Use como fonte choosealicense.com, opensource.org, creativecommons.org e a documentação do GitHub. Informe a data de acesso.
- Separe o que é fato (texto da licença, resultado da busca) do que é opinião (o quanto um nome é bom).

## Pronto quando
- Cada nome tem o resultado da checagem de conflito no GitHub.
- A licença recomendada vem com o identificador SPDX e o link do texto oficial.

## Autonomia
Suposições: confirme: o nome pode ser em inglês, para alcançar mais gente, mesmo com a documentação em português. Confirme: o objetivo é permitir reuso amplo com atribuição, sem exigir que trabalhos derivados sejam abertos. Diga se alguma estiver errada.

## Formato da resposta
1. Resposta direta: o nome e a licença recomendados, em 1–2 frases.
2. Tabela de nomes: nome | o que comunica | conflitos no GitHub | observação.
3. Tabela de licenças: licença (SPDX) | reuso/modificação | atribuição | serve para texto ou código | detecção no GitHub.
4. Recomendação com confiança (alta, média ou baixa) e o porquê.
5. Fontes: link e data.
```
